# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| 0.1.x   | Yes, until 0.2.x is on npm |
| < 0.1.0 | No        |

## Reporting a vulnerability

Do not open a public GitHub issue for a security report.

Prefer [GitHub private vulnerability reporting](https://github.com/hrashkan/layout-manager-react/security/advisories/new) on this repository. If that form is unavailable, email hooshidarashkan@gmail.com with:

- The affected version
- A description of the issue
- Steps to reproduce, or a proof of concept if you have one

You should hear back within 7 days. If the report is accepted, a fix will be prepared privately and released in a patch version before details are published.
